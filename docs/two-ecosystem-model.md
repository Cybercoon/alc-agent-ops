# ALC Two-Ecosystem Model

## AI Council of Agents (meta-layer)
Purpose: Continuously develop, modify, and improve agent infrastructures.
Role: BUILD and GOVERN — not operate within the infrastructure.
Agents: Professor X (orchestrator), Architect (implementer), + council reviewers
Key principle: Every lesson learned building the ALC fleet is captured here and applied to the Council's own operating standards.

## ALC/Sisu Agent Fleet (business layer)
Purpose: Execute specific business functions for ALC and Sisu.
Role: OPERATE — prospect research, CRM, delivery, marketing.
Agents: Beast (CRM/Delivery), Wolverine (Prospect/Marketing), Magneto (parked), Forge (parked)

## Shared infrastructure
- Shared filesystem: /opt/data/shared/ across all containers
- Mem0 persistent memory: two namespaces — council / alc-fleet
- Wiki (/docs): serves both ecosystems
- GitHub: this repo — version controls both ecosystems
